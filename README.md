# Jalendar
There are a lot of calendars out there, including a lot of bad ones. At least, in my opinion. So, I decided to make my own calendar/task manager. I'll update this description more as the project is more developed!

This project is built using Spring Boot, with a PostgreSQL database behind it. Currently, the frontend is JavaScript/HTML, though I do intend to transition it to React as I get more comfortable with the project!

WARNING: I have never been responsible for the security of a project before. As of this moment, there is effectively ZERO security on any data put into the database, and I'm not even 100% sure it would work
on a device other than my own. Even as I work on implementing security, it's worth noting that I have little to no work experience in security. PLEASE do not put sensitive information into the program, do not
use the same password you use for anything else. I will do my best to secure it as time goes on, but I make no guarantees of data security at this time!
